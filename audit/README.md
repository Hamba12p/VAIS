# Historical audit and branch consolidation

The `baseline` captures, inventory and audit scripts came from the older
`kepler/full-spectrum-audit-improvement` branch at `f841278`. They describe the
site before the signal-atlas redesign. They are not current production evidence.
The scripts retain their original local browser and tool-cache prerequisites.

On 11 November 2026, consolidation onto `main` combined that branch with the
latest `visuals-language-pass` work at `ea8c420` and both GitHub main histories,
including `VAIS/main` at `f6d02fc`.

Merge resolution kept the current home, practice, portfolio, project pages,
navigation, typography and architecture explorer. These already supersede the
older audit layouts and incorporate its visible-content and navigation fixes.
The merge retained the older audit records, reusable catalogue and operating-path
components, the corrected legacy vignette extension, sandbox heading and pressed
states, and contact-field maximum lengths.

Uncommitted edits in the separate audit worktree were excluded from the merge
and preserved in that worktree. Consolidation includes committed history only.
